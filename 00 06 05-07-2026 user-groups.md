# AWS EC2 Linux Instance - Connect, User Management & Docker Setup

## Objective

Learn how to:

* Start a stopped EC2 Linux instance
* Connect using SSH
* Create Linux users and groups
* Manage file ownership and permissions
* Install and configure Docker
* Deploy an Nginx container

---

# Part 1: Start a Stopped EC2 Instance

### Step 1: Login to AWS

* Login to the AWS Management Console.
* Select the required AWS Region.

### Step 2: Open EC2 Dashboard

* Search for **EC2**
* Open **EC2 Dashboard**

### Step 3: Select the Instance

* Click **Instances**
* Select the **Stopped** EC2 instance.

### Step 4: Start the Instance

Click

**Instance State → Start Instance**

Wait until:

* Instance State = **Running**
* Status Checks = **2/2 Checks Passed**

---

# Part 2: Connect to EC2 (Linux)

### Method 1 - PowerShell

Open **PowerShell**

```bash
cd Downloads
chmod 400 "key.pem"

ssh -i "key.pem" ec2-user@ec2-54-226-232-234.compute-1.amazonaws.com
```

# Part 3: Create Linux User & Group

## Create User

```bash
sudo useradd atul
```

---

## Create Group

```bash
sudo groupadd dev
```

---

## Add User to Group

```bash
sudo usermod -aG dev atul
```

---

## Set Password

```bash
sudo passwd atul
```

---

## Switch User

```bash
sudo su - atul
```

---

## Verify User Information

```bash
id
```

Example Output

```text
uid=1001(atul)
gid=1002(atul)
groups=1002(atul),1003(dev)
```

# Part 4: File Ownership Practice

Login as **ec2-user**

Create a file

```bash
touch a.txt
```

View file details

```bash
ls -la
```

Change file owner

```bash
sudo chown atul a.txt
```

Verify ownership

```bash
ls -la
```

Move file to user's home directory

```bash
sudo mv a.txt /home/atul
```

Switch user

```bash
su atul
```

Enter password when prompted.

Go to home directory

```bash
cd
```

Verify file

```bash
ls -la
```

Change group ownership

```bash
sudo chgrp atul /home/atul/a.txt
```

Verify ownership

```bash
sudo ls -la /home/atul/a.txt
```

# Part 5: Docker Installation

> **Note**
>
> Amazon Linux uses **yum**.
>
> Ubuntu uses **apt**.

---

## Amazon Linux

```bash
sudo yum install docker -y
```

---

## Ubuntu

```bash
sudo apt install docker.io -y
```

---

## Verify Installation

```bash
docker --version
```

---

## Start Docker Service

```bash
sudo systemctl start docker
```

---

## Enable Docker on Boot

```bash
sudo systemctl enable docker
```

---

## Check Docker Status

```bash
sudo systemctl status docker
```

---

## View Docker Images

```bash
docker images
```

---

## Allow Current User to Run Docker

```bash
sudo usermod -aG docker ec2-user
```

Apply the new group without logging out:

```bash
newgrp docker
```

---

# Part 6: Docker Practice

Pull the Nginx image

```bash
docker pull nginx
```

List downloaded images

```bash
docker images
```

Run an Nginx container

```bash
docker run -d -p 80:80 --name nginx-container nginx
```

List running containers

```bash
docker container ls
```

Open the application in a browser

```
http://<EC2-Public-IP>
```

Example

```
http://54.226.232.234
```

---

# Part 7: Cleanup

Stop the container

```bash
docker stop nginx-container
```

Remove the container

```bash
docker rm nginx-container
```

Remove unused Docker resources

```bash
docker system prune -a
```

# Learning Outcomes

After completing this lab, you will be able to:

* Start and connect to an EC2 Linux instance.
* Use SSH with a PEM key.
* Create Linux users and groups.
* Manage file ownership and permissions using `chown` and `chgrp`.
* Install Docker on Amazon Linux or Ubuntu.
* Start and enable the Docker service.
* Pull Docker images from Docker Hub.
* Deploy an Nginx container.
* Access a web application hosted inside a Docker container.
* Clean up Docker images and containers.
